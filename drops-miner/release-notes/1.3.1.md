**Bonkr Twitch Miner** mines Twitch and Kick drops in the background on Windows. It is a **port of [Twitch Drops Miner by DevilXD](https://github.com/DevilXD/TwitchDropsMiner)** from Python to Rust and Tauri, with a new window: Overview, Channels, Inventory, Activity, Settings and Account.

## New in 1.3.1: Kick drops

- **Mine Kick drops too.** Turn it on under **Settings › Kick**, sign in to Kick once, and it mines Kick campaigns alongside Twitch, on its own channel, with the same game lists.
- A **Twitch | Kick** switch on Overview, Channels and Inventory. Kick pages use Kick green.
- Kick claims finished rewards by itself and shows **Link account** for campaigns that need your game account linked to Kick.
- Kick's firewall only lets real browsers through, so Kick runs in a hidden browser window inside the app. No fingerprint tricks, no extra software.

Fixed in 1.3.1: the app froze when you clicked Sign in to Kick (or the Twitch Sign in button).

Kick's drops API is unofficial and newer than Twitch's, so expect it to need fixes now and then. If Kick misbehaves, the **Activity** page says what happened (Kick lines start with "Kick:").

## Download

Download **Bonkr.Twitch.Miner_1.3.1_x64-setup.exe** under **Assets** below (Windows 10 and 11, 64-bit, about 3 MB).

1. Run the installer. Windows may show **"Windows protected your PC"** because the app isn't code-signed. Click **More info**, then **Run anyway**.
2. Open Bonkr Twitch Miner and sign in to Twitch in the window that opens. Only the sign-in token is kept, on your PC.
3. Go to **Settings** and add the games you want drops for, most wanted first. Then click **Save and reload**.

It keeps mining in the tray when you close the window. Quit from the tray icon.

## What it does

- Picks the best live channel for your games and switches when a better one goes live
- Follows drop progress live and claims every drop as soon as it's ready, with a Windows notification
- **Featured for you**: the next rewards for your games, right on the Overview page
- Pin a channel with **Watch**, or let the miner choose
- Your game lists are also backed up to `Documents\Bonkr Twitch Miner`, so they survive reinstalls

Like the original, it never downloads video. It only asks Twitch for each stream's playlist, so it uses almost no bandwidth.

## Good to know

- Twitch only counts one channel at a time per account, so the miner watches one channel.
- Campaigns that need a linked game account show **Link account** until you link it.
- Twitch changes its private API every so often. When the original miner gets a fix, this one gets an update.
